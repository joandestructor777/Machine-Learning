## 📌 Descripción del Proyecto

Este proyecto consiste en el análisis de un dataset de **enfermedades cardíacas** utilizando **Google Colab como plataforma SaaS**.  
El objetivo principal es aplicar técnicas de **Machine Learning** para predecir la presencia o ausencia de enfermedad cardíaca a partir de variables clínicas como edad, presión arterial, colesterol, frecuencia cardíaca, entre otras.  

El análisis incluye:  
- Exploración de datos (EDA) para identificar patrones y relaciones entre variables.  
- Preprocesamiento de los datos para mejorar la calidad de la información.  
- Entrenamiento y evaluación de distintos algoritmos de clasificación.  
- Extracción de conclusiones y recomendaciones útiles para la toma de decisiones en el área de salud.  

---

## 🎯 Objetivos del Proyecto

**Objetivo General:**  
Desarrollar un análisis de datos reproducible que, mediante algoritmos de clasificación en Machine Learning, permita predecir el riesgo de enfermedad cardíaca y generar insights relevantes para la práctica médica y la toma de decisiones.  

**Objetivos Específicos:**  
1. Utilizar **Google Colab** como plataforma SaaS para el análisis de datos médicos.  
2. Implementar técnicas de **exploración y limpieza de datos (EDA)** para identificar tendencias, valores atípicos y correlaciones.  
3. Aplicar y comparar al menos dos algoritmos de **Machine Learning de clasificación** (ejemplo: Regresión Logística y Random Forest).  
4. Evaluar el rendimiento de los modelos mediante métricas apropiadas (**accuracy, precisión, recall, f1-score, ROC-AUC**).  
5. Documentar el proceso de forma clara y reproducible, incluyendo visualizaciones y conclusiones fundamentadas.
